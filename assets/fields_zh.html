混沌流演示向量场

演示向量场

以下是演示中包含的向量场列表，建议按顺序依次体验。

简单旋转

这是一个顺时针方向的简单旋转。

x' =     y + p*saw(x)
y' = -x    + p*saw(y)

向量记法：

v' = [ 0  1]v  + 摄动
     [-1  0]

v = [x]
    [y]

摄动是依赖于参数的锯齿波函数。在流场中添加若干粒子并点击“播放”，可看到它们呈顺时针圆形流动。

增大参数值后，粒子的运动轨迹将偏离先前的轨道。

勾选“Fld”复选框以显示向量场。由于向量场有界，每个粒子的运动轨迹都是平滑的，且完全由其初始位置决定。这意味着粒子轨迹之间永远不会相交。

勾选“Iso”复选框以显示等斜线。这些是向量场在x或y方向分量为0的曲线。当x' = 0时，向量场为垂直方向；当y' = 0时，向量场为水平方向。若 两者均为0，粒子将静止不动，这称为动力系统的驻点（平衡点）。

螺旋 – 稳定平衡点与不稳定平衡点

在上一示例的基础上，引入x'对x以及y'对y的线性依赖：

x' = p*x +   y
y' =  -x + p*y

初始时p = 0，与上述旋转完全一致。在中心(0,0)处存在一个平衡点。

将参数向左滑动（p < 0），粒子将盘旋螺旋汇聚向平衡点。这是一个稳定平衡点，其附近的粒子将始终保持在附近。

将参数向右滑动（p > 0），粒子将盘旋螺旋远离平衡点。这是一个不稳定平衡点。

观察等斜线分隔的各区域，在每个区域内粒子都倾向于朝特定象限方向运动。

搅拌 (Stir)

这是一个具有多个平衡点的示例，其中部分稳定，部分不稳定。若在不稳定平衡点附近放置粒子，粒子会漂移离开并向稳定平衡点靠近。

x' = -0.2 x^3 + saw(y, y_cent)
y' = -0.2 y^3 - saw(x, x_cent)

调整参数后，平衡点开始移动，粒子随之移动，形成复杂的混沌图景。

由于方程是光滑的，初始彼此靠近的粒子在短期内仍将保持接近；但在经过足够长的时间后，它们终将分道扬镳。

这展现了微积分的一个表观悖论：对于给定的固定时间t，位置(x(t), y(t))随初始点(x(0), y(0))连续变化；但若让t无限增长， 这种连续性在实际观测中将不复存在。

该示例包含一个随时间移动的吸引子：最终所有粒子都会紧密围绕四个吸引子点之一盘旋。

具有奇异吸引子的混沌系统

本示例选自参考资料中的专著。

x'(t) = 0.7y + 10x(0.1-y^2)
y'(t) = -x + 0.25 sin(1.57t)

尽管系统是混沌的，但它具有吸引子。吸引子并非简单曲线：随时间推进，吸引子会发生分离并向自身折叠。粒子分散后会重新聚集，但相对顺序发生了置换。

添加一组粒子网格，观察相似颜色的粒子如何在最初保持紧凑，随后充分混合—其过程令人联想到揉面团或锻打大马士革钢。
