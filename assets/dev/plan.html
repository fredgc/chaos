Chaos Flow Demo Plan

This document outlines the strategic roadmap, mathematical foundations, and long-term milestones for the Chaos Flow Demo project.

Note: Active day-to-day tasks and issue tracking are managed dynamically using ~/bin/todo.py. Run ~/bin/todo.py list to view active tasks.

1. Mathematical Models & Systems

The application illustrates dynamic systems, vector fields, and chaotic flow:

1.1 Pure Rotation with Perturbation (Rotate)

ẋ(t)=−3y+saw(x),ẏ(t)=3x+saw(y)\dot{x}(t) = -3y + \text{saw}(x), \quad \dot{y}(t) = 3x + \text{saw}(y)

Demonstrates smooth periodic trajectories, uniqueness of solutions, and how time-dependent perturbations alter path crossing behavior.

1.2 Stirring Flow (Stir)

ẋ(t)=−0.2x3+3f(y,ycent),ẏ(t)=−0.2y3−3f(x,xcent)\dot{x}(t) = -0.2 x^3 + 3 f(y, y_{\text{cent}}), \quad \dot{y}(t) = -0.2 y^3 - 3 f(x, x_{\text{cent}})

Where ff represents localized shearing or stirring teeth. Showcases sensitive dependence on initial conditions and folding behavior.

1.3 Strange Attractor (Chaos)

ẋ(t)=0.7y+10x(0.1−y2),ẏ(t)=−x+0.25sin⁡(1.57t)\dot{x}(t) = 0.7 y + 10x(0.1 - y^2), \quad \dot{y}(t) = -x + 0.25 \sin(1.57 t)

Exhibits a chaotic strange attractor that folds continuously in state space, generating quasi-periodic behavior and fractal cross-sections.

2. Numerical Integration & Particle Dynamics

  • Runge-Kutta Integration: Transition from simple Euler stepping to adaptive 4th-order Runge-Kutta (RK4) to ensure particle motes remain bounded and conserve energy over extended simulation runs.

  • Reversible Time & Error Measurement: Provide a time-reversal toggle to simulate backward flow and compute numerical drift / Lyapunov exponent estimates.

  • Nullcline & Isocline Geometry: Solve and render horizontal (ẋ=0\dot{x} = 0) and vertical (ẏ=0\dot{y} = 0) nullclines dynamically across all parameter configurations.

3. Interactive Presentation & Educational Modes

  • Interactive Demonstration Walkthrough: Design step-by-step guided lessons explaining vector fields, phase portraits, and chaos theory.

  • Android Package Release: Prepare Android manifest and publish release package to Google Play.
