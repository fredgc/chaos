À propos de Démonstration de Flux du Chaos (v2.0.1+5)

La Démonstration de Flux du Chaos est une applicationéducative et interactive conçue pour illustrer les champs de vecteurs et les trajectoires des systèmes dynamiques—des oscillateurs harmoniques simples aux systèmes chaotiques dotés d’attracteursétranges.

Consultez la Vue d’ensemble pour une explication des systèmes dynamiques, ou les Commandes pour savoir comment utiliser le programme.

Cette application estécrite en Dart avec Flutter—le code source est disponible sur GitHubàl’adresse [https://github.com/fredgc/chaos][github].

Vous avez trouvéun bug ou souhaitez proposer une amélioration ? [Ouvrez un ticket sur GitHub][issues].

D’autres applications et outils de dessin sont disponibles sur [www.gchouse.org][gchouse].

Confidentialité et rétention des données

Ce programme vous permet de personnaliser des paramètres enregistrés localement sur votre appareil (avec SharedPreferences / LocalStorage). Aucune donnée personnelle n’est collectée.

Sur Android, les paramètres locaux sont effacés lors de la désinstallation de l’application. Sur le Web, ils sont effacés lorsque vous videz les données de l’application dans votre navigateur.
