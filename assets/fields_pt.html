Campos de Demonstração de Caos

Campos demonstrados

Aqui estáa lista dos campos vetoriais demonstrados. Recomendamos analisá-los na ordem apresentada.

Rotação simples

Trata-se de uma rotação simples no sentido horário.

x' =     y + p*saw(x)
y' = -x    + p*saw(y)

Em notação vetorial:

v' = [ 0  1]v  + perturbação
     [-1  0]

v = [x]
    [y]

A perturbaçãoéuma onda dente de serra dependente do parâmetro. Adicione algumas partículas e clique em„reproduzir“. Vocêas veráfluindo em círculos no sentido horário.

Aumente o valor do parâmetro e as partículas se desviarão ligeiramente das suas trajetórias originais.

Ative a opção„Campo“para exibir o campo vetorial. Como o campo vetorialé limitado, a trajetória de cada partículaésuave e inteiramente determinada por seu ponto inicial. Portanto, as partículas nunca se cruzam.

Ative„Iso“para exibir as isóclinas. Estas são as curvas onde a componente x ou y do campo vetorialénula. Se x' = 0, o campoévertical. Se y' = 0, o campoé horizontal. Se ambas forem 0, a partícula permanece imóvel: trata-se de um ponto de equilíbrio (estacionário) do sistema dinâmico.

Espiral – ponto estável versus instável

Modificamos o exemplo anterior introduzindo uma dependência linear de x' em relação a x e de y' em relação a y:

x' = p*x +   y
y' =  -x + p*y

Inicialmente, p = 0, o que coincide com a rotação acima. Háum ponto estacionário na origem (0,0).

Mova o parâmetro para a esquerda (p < 0): as partículas espiralam em direção ao ponto estacionário. Trata-se de um ponto estacionário estável.

Mova o parâmetro para a direita (p > 0): as partículas espiralam para longe do ponto estacionário. Trata-se de um ponto estacionário instável.

Observe as regiões separadas pelas isóclinas. Em cada região, as partículas tendem a se mover para um quadrante específico.

Mistura (Stir)

Este exemplo possui múltiplos pontos estacionários—alguns estáveis e outros instáveis. Partículas próximas a um ponto instável se afastam dele e convergem para os pontos estáveis.

x' = -0.2 x^3 + saw(y, y_cent)
y' = -0.2 y^3 - saw(x, x_cent)

Ao alterar o parâmetro, os pontos estacionários se deslocam, conduzindo as partículas a um padrão caótico.

Como as equações são suaves, partículas que começam próximas permanecem próximas no curto prazo. Com o tempo, contudo, elas acabam divergindo.

Isso exemplifica um aparente paradoxo do cálculo: para um t fixo, a posição (x(t), y(t)) varia continuamente em relação a (x(0), y(0)). Se deixarmos t crescer indefinidamente, essa continuidade perde relevância prática.

Este exemplo possui um atrator móvel no tempo: eventualmente todas as partículas terminam orbitando estreitamente em torno de um dos quatro pontos do atrator.

Sistema caótico com atrator estranho

Este exemplo foi extraído da obra citada nas referências.

x'(t) = 0.7y + 10x(0.1-y^2)
y'(t) = -x + 0.25 sin(1.57t)

Embora caótico, este sistema possui um atrator. O atrator nãoéuma curva simples: com o avanço do tempo, ele se divide e se dobra sobre si mesmo. As partículas se dispersam e tornam a se reunir em uma ordem diferente.

Adicione uma grade de partículas e observe como as cores semelhantes permanecem próximas inicialmente e depois se misturam intimamente—lembrando o sovar de um pão ou o forjar de aço.
