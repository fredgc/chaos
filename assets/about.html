About Chaos Flow Demo (v{{ VERSION }})

The Chaos Flow Demo is an interactive educational application designed to illustrate the flow fields and trajectories of dynamical systems, from simple harmonic oscillators to chaotic systems featuring strange attractors.

See the Overview for an explanation of dynamical systems, or see Controls for instructions on using the program.

This application is written in Dart with Flutter—the source code is available on GitHub at [https://github.com/fredgc/chaos][github].

Found a bug or have a feature request? [File an issue on GitHub][issues].

Other apps and drawing tools can be found at [www.gchouse.org][gchouse].

Privacy and Data Retention

This program allows you to customize settings that are saved locally on your device (using SharedPreferences / LocalStorage). No personal data is collected.

On Android, local settings are deleted when you uninstall the app. On Web, settings are deleted when you clear your browser’s local application data.
