描画されるベクトル場の一覧です。番号順にご覧いただくことをおすすめします。

単純な回転

時計回りの単純な回転です。

x' =     y + p*saw(x)
y' = -x    + p*saw(y)

ベクトル表記：

v' = [ 0  1]v  + 摂動
     [-1  0]

v = [x]
    [y]

摂動はパラメータに応じた鋸歯状関数です。粒子を追加して「再生」をクリックすると、時計回りの円を描いて流れます。

パラメータを大きくすると、粒子は元の軌道からわずかにずれるようになります。

「Fld」チェックボックスをオンにするとベクトル場が表示されます。ベクトル場が有界であるため、各粒子の軌道は滑らかで、初期位置によって完全に決定されます。し たがって、粒子の軌道同士が交差することはありません。

「Iso」チェックボックスをオンにすると等傾斜線が表示されます。これはベクトル場のx成分またはy成分が0になる曲線です。x' = 0の場合はベクトル場が 垂直になり、粒子は垂直に移動します。y' = 0の場合は水平に移動します。両方が0の場合、粒子は静止します。これは力学系の平衡点（停留点）と呼ばれます。

渦巻（スパイラル） – 安定平衡点と不安定平衡点

前の例を変更し、x'のxに対する線形依存性とy'のyに対する線形依存性を追加します：

x' = p*x +   y
y' =  -x + p*y

開始時（p = 0）は上記の回転と同一です。中心(0,0)に平衡点が存在します。

パラメータを左に動かしてp < 0にすると、粒子は平衡点に向かって渦を巻いて収束します。これは安定平衡点です。平衡点の近くから始まった粒子はその近傍にと どまります。

パラメータを右に動かしてp > 0にすると、粒子は平衡点から渦を巻いて離れていきます。これは不安定平衡点です。

等傾斜線で区切られた領域に着目してください。各領域で、粒子は特定の象限方向（右上、左上、右下、左下）へ向かう傾向があります。

攪拌（Stir）

複数の平衡点を持つ例です。安定なものと不安定なものが混在しています。不安定な平衡点の近くに粒子を配置すると、離れていき、やがて安定な平衡点へと近づきます。

x' = -0.2 x^3 + saw(y, y_cent)
y' = -0.2 y^3 - saw(x, x_cent)

                   /\  /
 saw(x,c) =       /  \/
                 /

パラメータを変更すると平衡点が移動し始め、粒子がそれを追従してカオス的な乱れが生じます。

方程式が滑らかであるため、互いに近くから始まった粒子は短期的には近くにとどまります。しかし、十分な時間が経過すると離れていきます。

これは微分積分のパラドックスのように見えます。ある固定されたtに対しては、位置(x(t), y(t))は初期位置(x(0), y(0))に対して 連続的に変化します。しかしtを大きくしていくと、その連続性は実質的に失われます。

この例には時間とともに移動するアトラクターがあり、最終的にすべての粒子は4つのアトラクター点のいずれかの周りを密集して回転します。

ストレンジアトラクターを持つカオス系

参考書籍に掲載されている例です。

x'(t) = 0.7y + 10x(0.1-y^2)
y'(t) = -x + 0.25 sin(1.57t)

この系はカオス的ですが、アトラクターを持ちます。アトラクターは単純な曲線ではなく、時間が進むにつれて分離し、自身へと折り畳まれます。粒子は離散したあと再び集 まりますが、その順序は入れ替わっています。

粒子の格子を追加し、最初は似た色の粒子が近くに留まり、次第に混ざり合っていく様子を観察してください。パンを捏ねたり、鋼を鍛造したりする過程に似ています。
