# Politique de confidentialité

Chaos Dynamic System Demo respecte votre vie privée.

## Principes

* **Traitement local** : Toutes les simulations de systèmes dynamiques
  s'exécutent entièrement sur votre appareil.

* **Aucun compte requis** : L'utilisation de l'application ne nécessite aucune
  inscription ni connexion.

* **Aucun suivi** : Aucune donnée d'identification personnelle n'est
  collectée.
