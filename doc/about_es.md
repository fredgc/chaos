La **Demostración de Flujo del Caos** es una aplicación educativa interactiva
diseñada para ilustrar los campos de flujo y las trayectorias de sistemas
dinámicos, desde osciladores armónicos simples hasta sistemas caóticos con
atractores extraños.

Consulte el [Resumen](help_es.html) para obtener una explicación de los
sistemas dinámicos, o consulte [Controles](controls_es.html) para ver las
instrucciones de uso del programa.

Esta aplicación estáescrita en Dart con Flutter; el código fuente está
disponible en GitHub en [https://github.com/fredgc/chaos][github].

¿Encontróun error o tiene una solicitud de función? [Abra un problema en
GitHub][issues].

Otras aplicaciones y herramientas de dibujo se encuentran en
[www.gchouse.org][gchouse].

## Privacidad y Retención de Datos

Este programa le permite personalizar ajustes que se guardan localmente en su
dispositivo (usando SharedPreferences / LocalStorage). No se recopilan datos
personales.

En Android, los ajustes locales se eliminan al desinstalar la aplicación. En
la Web, los ajustes se eliminan al borrar los datos de la aplicación local de
su navegador.
