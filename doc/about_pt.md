A **Demonstração de Fluxo do Caos**éum aplicativo educacional interativo
projetado para ilustrar os campos de fluxo e as trajetórias de sistemas
dinâmicos—desde osciladores harmônicos simples atésistemas caóticos com
atratores estranhos.

Consulte a [Visão Geral](help.html) para uma explicação sobre sistemas
dinâmicos, ou veja os [Controles](controls.html) para instruções de uso do
programa.

Este aplicativo foi desenvolvido em Dart com Flutter—o código-fonte está
disponível no GitHub em [https://github.com/fredgc/chaos][github].

Encontrou um erro ou tem uma sugestão de recurso? [Abra uma issue no
GitHub][issues].

Outros aplicativos e ferramentas de desenho podem ser encontrados em
[www.gchouse.org][gchouse].

## Privacidade e Retenção de Dados

Este programa permite personalizar configurações que são salvas localmente no
seu dispositivo (utilizando SharedPreferences / LocalStorage). Nenhum dado
pessoalécoletado.

No Android, as configurações locais são excluídas ao desinstalar o aplicativo.
Na Web, as configurações são excluídas ao limpar os dados locais de navegação
do aplicativo.
