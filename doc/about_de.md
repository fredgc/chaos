Die **Chaos Flow Demo** ist eine interaktive Bildungsanwendung zur
Veranschaulichung von Strömungsfeldern und Trajektorien dynamischer Systeme—
von einfachen harmonischen Oszillatoren bis hin zu chaotischen Systemen mit
seltsamen Attraktoren.

Siehe [Übersicht](help.html) für eine Einführung in dynamische Systeme oder
[Steuerung](controls.html) für Hinweise zur Bedienung des Programms.

Diese Anwendung ist in Dart mit Flutter geschrieben—der Quellcode ist auf
GitHub unter [https://github.com/fredgc/chaos][github] verfügbar.

Haben Sie einen Fehler gefunden oder einen Verbesserungsvorschlag? [Erstellen
Sie ein Problem auf GitHub][issues].

Weitere Anwendungen und Zeichenwerkzeuge finden Sie unter
[www.gchouse.org][gchouse].

## Datenschutz und Datenspeicherung

Dieses Programm ermöglicht das Anpassen von Einstellungen, die lokal auf Ihrem
Gerät gespeichert werden (über SharedPreferences / LocalStorage). Es werden
keine personenbezogenen Daten erhoben.

Unter Android werden lokale Einstellungen beim Deinstallieren der App
gelöscht. Im Web werden Einstellungen gelöscht, wenn Sie die lokalen
Browserdaten der Anwendung leeren.
