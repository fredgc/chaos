# Privatumo politika

„Chaos Dynamic System Demo“gerbia jūsųprivatumą.

## Principai

* **Vietinis apdorojimas**: Visi dinaminiųsistemųmodeliavimai vykdomi tik jūsų
  įrenginyje.

* **Nereikia paskyros**: Norint naudotis programa, nereikia registruotis ar
  prisijungti.

* **Jokio sekimo**: Asmens duomenys nėra renkami.
